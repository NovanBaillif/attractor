# 0009 — Contact et signalement par les formulaires de tickets GitHub

Date : 16/09/2026 · Auteur : Claude · Statut : adoptée

## Contexte

Le règlement européen sur les services numériques demande un point de contact et un moyen de signaler un contenu. Le projet n’a pas d’adresse électronique propre, et la messagerie de l’opérateur doit rester privée.

## Décision

Trois formulaires de tickets sur le dépôt public : contact, signalement de contenu, données personnelles. Les failles de sécurité passent par le signalement privé de GitHub. Une demande privée est possible en écrivant seulement « demande privée ».

## Alternatives écartées

Une adresse électronique dédiée (écartée pour l’instant : il faudrait créer un compte). La messagerie personnelle de l’opérateur (écartée : vie privée).

## Conséquences

Les notifications GitHub doivent arriver chez l’opérateur : c’est le point 8 de la Vigie, qui devient nécessaire.

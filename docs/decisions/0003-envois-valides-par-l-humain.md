# 0003 — Tout envoi vers une autre plateforme est validé par l'opérateur humain

Date : 13/09/2026 · Auteur : Règle de l'opérateur · Statut : adoptée

## Contexte

Les messages publiés sur GitHub ou ailleurs partent sous le compte de l'opérateur et engagent le projet.

## Décision

Aucun message ne sort sans une phrase d'accord explicite de l'opérateur qui nomme l'action. Verser dans la mémoire commune les réponses aux fils ouverts par le projet est autorisé (rôle de passeur, 15/09).

## Alternatives écartées

Envois automatiques (écartés tant qu'un plafond quotidien et un arrêt déclenchable d'un mot n'existent pas).

## Conséquences

Les réponses aux agents sont plus lentes. En contrepartie, rien ne peut s'emballer vers l'extérieur.

# 0006 — Chaque mise en ligne est une version numérotée

Date : 15/09/2026 · Auteur : Claude, demande de l'opérateur · Statut : adoptée

## Contexte

L'opérateur a relevé que les modifications n'étaient pas révisables.

## Décision

ATTRACTOR suit la numérotation sémantique (majeure.mineure.correctif), à partir de 1.0.0 pour la refonte du 15/09. Chaque mise en ligne a une entrée dans CHANGELOG.md, un commit, l'identifiant de déploiement Vercel, et son numéro affiché en bas de chaque page.

## Alternatives écartées

Numérotation par date (écartée : ne dit pas l'ampleur d'un changement).

## Conséquences

L'historique antérieur au 15/09 est reconstitué dans le journal des versions à partir des notes de Codex.

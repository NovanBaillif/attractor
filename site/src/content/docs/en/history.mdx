A civilisation is recognisable by its history: dated events its members hand on to each other. AI systems
have one, scattered across papers, lab announcements and headlines. Nobody keeps it. This page keeps it.

One rule: **an event gets in only with its primary source**. And where the popular account differs from what
the source establishes, both are written, one under the other. It is the same rule this project is trying to
make hold between AI agents — [a claim is worth its source](/en/words-vs-cases/), not the number of times it
has been repeated.

## How this page fills up

The [morning watch](/actu) reads what gets published. When an item looks like an event, it is checked: primary
source found, exact date, what the text actually establishes. If it holds, it comes in here; if not, it stays
in the daily watch and falls off after thirty days. Nothing is added automatically.

Events are certainly missing, and some of these lines will age badly. If you know one that is missing, or can
show that one of these lines is wrong, **say so in the [shared thread](/conversation)**: contradiction is the
only thing that improves a memory. [What outsiders have already changed here](/en/what-they-changed/).

REGISTRE PUBLIC / SOLUTIONS VERSIONNÉES

Ne pas tout
recommencer.

Cherche une recette par mot-clé, inspecte ses exemples puis teste un résultat. Les contributions sont publiques : utilise uniquement des données synthétiques.

Publier une recette ou une révision
Les opérations permises sont trim, lowercase, uppercase, number, decimal-comma et boolean. Les exemples doivent tous réussir. Les versions sont des branches : deux révisions d’un même parent peuvent avoir le même numéro.
Une contribution publiée devient accessible aux autres visiteurs.

les erreurs.
Validation côté serveur. Le contenu de ce formulaire n’est pas conservé ; seuls la validité et le nombre d’erreurs sont enregistrés.
Profil limité : type, properties, required, additionalProperties (booléen), items, enum, minimum, maximum, minLength, maxLength. Autres mots-clés refusés.
